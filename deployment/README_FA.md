# نسخه آزمایشی رایگان روی Render

این تنظیمات فقط برای تست هستند. سایت چابکان، دیتابیس و رسانه‌های اصلی تغییر نمی‌کنند.

## ساخت سرویس

1. این لینک را باز کنید و با حساب خودتان وارد Render شوید:
   https://render.com/deploy?repo=https://github.com/MohammadMHB/FitCoachClub&branch=deploy/render-demo
2. سرویس با plan: free را تأیید کنید. تنها یک سرویس وب ساخته می‌شود؛ دیتابیس یا دیسک پولی در این Blueprint وجود ندارد.
3. پس از پایان Deploy، آدرس onrender.com سرویس را باز کنید.
4. برای ورود، در پنل سرویس بخش Environment مقدار DEMO_LOGIN_PASSWORD را ببینید.
   نام‌های کاربری: admin (مدیر)، coach1 (مربی)، trainee1 (شاگرد).
   رمز مشترک این سه حساب همان مقدار تصادفی DEMO_LOGIN_PASSWORD است. آن را در مخزن ثبت نکنید.

## محدودیت‌های پلن رایگان

طبق مستندات Render، سرویس پس از ۱۵ دقیقه بی‌استفاده بودن متوقف می‌شود و اولین بازدید بعدی ممکن است حدود یک دقیقه منتظر بماند.
دیسک موقت است: SQLite و آپلودها با ری‌استارت، استقرار مجدد یا توقف سرویس ممکن است پاک شوند.
برای داده واقعی مناسب نیست. اطلاعات چابکان و کلیدهای پیامک را به این سرویس منتقل نکنید.

حساب Render متصل نشده است؛ افزودن این فایل‌ها به GitHub به معنی ساخته شدن سرور نیست.
تعرفه‌ها و نیاز احتمالی سرویس به تأیید حساب را در صفحه ساخت Render بررسی کنید. هیچ پلن پولی انتخاب نکنید.
